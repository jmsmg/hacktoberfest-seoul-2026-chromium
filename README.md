# Hacktoberfest Seoul 2026 · Chromium 테이블

Chromium `docs/` 폴더의 마크다운에서 **없는 파일을 가리키는 링크 한 줄**을 고쳐 Gerrit에 CL을 올리는 이슈 카드 모음입니다. 빌드가 없고, 소스는 1분이면 받습니다.

**가이드: https://jmsmg.github.io/hacktoberfest-seoul-2026-chromium/** — 사전 준비, 첫 CL 올리기, 리뷰 받기, 막혔을 때, 이슈 카드 목록이 있습니다.

- 카드 한 장 = 파일 하나. 라벨 `쉬움`은 링크 한 줄만 바꾸면 끝, `보통`은 새 위치를 찾거나 문장을 손봐야 합니다.
- 마음에 드는 카드에 **댓글로 "제가 할게요" 한 줄**을 남기고 시작하세요. 한 카드에 한 사람입니다.
- 올린 CL 링크는 그 카드 댓글에 남겨 주세요. 리뷰어 지정은 멘토와 같이 합니다.
- 업로드는 `git cl upload -f --hashtag=hacktoberfest-seoul-2026`.
- 라벨 `코드`가 붙은 C1~C10은 **집에서 하는 코드 카드**입니다. Chromium 전체를 받아 빌드하고 테스트를 돌려야 합니다. 순서는 가이드의 [코드 카드 안내](https://jmsmg.github.io/hacktoberfest-seoul-2026-chromium/code.html)에 있습니다.
- 이 저장소에는 PR을 보내지 않습니다. 고친 내용은 Chromium Gerrit에 CL로 올립니다.

멘토: 조성곤 (GitHub `jmsmg`). 리뷰 대응은 행사 뒤에도 Discord 스레드에서 같이 합니다.

가이드 사이트는 이 저장소의 `docs/` 폴더에서 GitHub Pages로 나갑니다. 디자인은 [OSSCA Chromium](https://github.com/OSSCA-chromium/contributions)(MIT)을 따랐습니다.
