막혔을 때

증상으로 찾아보고, 안 풀리면 명령과 출력을 그대로 보여 주며 멘토를 불러 주세요.

자주 나오는 오류#

증상 원인 해결
git: 'cl' is not a git command depot_tools가 PATH에 없다 PATH에 넣고 터미널을 새로 엽니다. Windows는 cmd.exe
… is not in AUTHORS file 경고 AUTHORS 줄 누락 AUTHORS에 추가하고 git commit -a --amend --no-edit 뒤 다시 업로드
email … is not registered in your account git 이메일이 Gerrit 계정 이메일과 다르다 git config --global user.email <Gerrit 이메일>, git cl creds-check, git commit --amend --reset-author --no-edit
could not read Username 또는 401 로그인이 안 됐다 git credential-luci login
presubmit ModuleNotFoundError / No such file or directory sparse로 받은 폴더가 모자란다 메시지에 나온 폴더를 git sparse-checkout add <폴더> 한 뒤 다시 업로드
subject longer than 72 characters 커밋 제목이 길다 git commit --amend로 줄입니다
vim이 열려서 못 나간다 core.editor를 안 정했다 Esc, :q!, Enter. 업로드에 -f를 붙이면 열리지 않습니다
Windows gclient가 이상하게 끝난다 PowerShell에서 실행했다 cmd.exe에서 다시
업로드 중 HTTP 503 / Failed to create a change 서버 일시 오류 git cl issue가 None이면 같은 명령을 다시
presubmit AttributeError: 'InputApi' … depot_tools가 오래됐다 update_depot_tools
googlesource.com 접속 실패 회사 프록시나 보안 소프트웨어 휴대폰 핫스팟이나 개인 노트북
리뷰어가 CL을 못 본다 아직 WIP 상태 Gerrit에서 Start Review
CV cannot start a Run … not a committer 또는 not a dry-runner 참가자가 CQ 버튼을 눌렀다 그대로 둡니다. 승인이 끝나면 리뷰어가 겁니다
CV cannot start a Run … Review-Enforcement +1이 두 개 모이기 전에 CQ +2를 걸었다 두 번째 +1을 기다립니다
git cl upload가 업스트림이 없다고 한다 브랜치를 git checkout -b로 만들었다 git branch --set-upstream-to=origin/main

셋업이 안 됐을 때#

  • 짝 작업. 셋업이 된 사람 옆에서 같은 카드를 함께 풉니다. CL 소유자는 노트북 주인이 되므로, 본인 CL은 집에서 이 가이드대로 만들고 Discord 스레드에 링크를 올립니다. 멘토가 같은 방식으로 봐 줍니다.
  • Gerrit 웹 편집. 멘토가 미리 확인한 경우에만 씁니다. 로그인 → Browse › Repositories › chromium/src › Commands › Create Change(branch main, subject는 4단계 양식의 제목) → Edit → 파일을 열어 고치고 AUTHORS에 한 줄 추가 → Publish Edit → Start Review. 로컬 presubmit이 돌지 않습니다. 봇 검사는 리뷰어가 Commit-Queue +2를 걸 때 돌고, 실패하면 고쳐서 다시 올립니다. 이 방법은 Google 계정과 CLA만 있으면 됩니다.
  • 집에서 이어서. 사전 준비를 끝내고 첫 CL 올리기의 0~5단계를 따라 합니다. 막히면 Discord 스레드에 증상과 명령 출력을 붙여 올립니다.
