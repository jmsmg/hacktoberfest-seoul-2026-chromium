  • GitHub 카드에는 고칠 줄 번호와 새 위치를 찾는 명령이 힌트로 적혀 있습니다.
  • 5번과 6번은 원인이 같아서 한 CL로 함께 고쳐도 됩니다.
  • 23번은 같은 파일을 고치는 다른 사람의 CL이 열려 있어서, 머지 전에 rebase가 필요할 수 있습니다.
  • 리뷰어 후보는 카드에 적혀 있고, 지정하기 전에 멘토와 확인합니다. 후보는 모두 커미터이고, 카드의 파일은 모두 OWNERS가 *라 이 후보들의 +1로 승인이 됩니다(10월 29일 확인).

집에서 하는 코드 카드#

Chromium 전체를 받아 빌드해야 하는 카드 10장입니다. 행사장에서는 하지 않고, 해 보고 싶은 분은 집에서 코드 카드 안내를 따라 합니다. 받기와 빌드, 테스트 순서는 코드 기여 가이드에 있습니다. 옛 해시 함수를 새 API로 바꾸는 일이고, 카드마다 돌려 볼 단위 테스트가 적혀 있습니다.

  1. C1 쉬움
    net: remove stale crypto/sha2 includes

    net/cert/cert_verify_proc.cc 외 4개
    #include "crypto/sha2.h" 줄만 지운다. cert_builder.cc는 std::array를 써서 #include <array>가 없으면 넣는다

    GitHub 카드 #31
  2. C2 쉬움
    safe_browsing/extension_telemetry: remove stale crypto/sha2 include

    chrome/browser/safe_browsing/extension_telemetry/potential_password_theft_signal_processor.cc
    #include "crypto/sha2.h" 줄만 지운다

    GitHub 카드 #32
  3. C3 쉬움
    chrome/services/file_util: remove stale crypto/sha2 includes

    chrome/services/file_util/public/cpp/sandboxed_rar_analyzer_unittest.cc 외 1개
    #include "crypto/sha2.h" 줄만 지운다

    GitHub 카드 #33
  4. C4 쉬움
    safe_browsing/phishing_classifier: remove stale crypto/sha2 include

    components/safe_browsing/core/common/phishing_classifier/scorer.cc
    #include "crypto/sha2.h" 줄만 지운다

    GitHub 카드 #34
  5. C5 쉬움
    payments: remove stale crypto/sha2 include

    components/payments/content/secure_payment_confirmation_app.cc
    #include "crypto/sha2.h" 줄만 지운다

    GitHub 카드 #35
  6. C6 보통
    password_manager/leak_detection: migrate to crypto/hash APIs

    components/password_manager/core/browser/leak_detection/encryption_utils.cc

  9. C9 보통
    web_package test_support: migrate to crypto/hash APIs

    GitHub 카드 #39
  10. C10 보통
