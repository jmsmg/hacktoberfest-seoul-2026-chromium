유용한 링크

기여할 때 자주 여는 사이트와 공식 문서입니다.

사이트#

사이트 쓰는 곳
Gerrit CL 올리기와 리뷰. crrev.com/c/<번호>가 CL 짧은 링크입니다
Code Search 파일·심볼 검색, 정의로 이동, blame
Gitiles 저장소 웹 보기. docs/의 마크다운이 여기서 렌더링됩니다
Issue Tracker 버그 추적. 커밋 메시지의 Bug: 538651940이 이 이슈입니다. crbug.com/<번호>가 짧은 링크
Google 개인 CLA 개인 기여자 라이선스 서명
depot_tools 안내 git cl, git new-branch가 들어 있는 도구 모음
