Chromium 문서 기여

Chromium 문서(docs/)에서 없는 파일을 가리키는 링크 한 줄을 고쳐 Gerrit에 첫 CL을 올립니다. 빌드는 하지 않고, 소스는 1분이면 받습니다.

사전 준비부터이슈 카드 보기

1개

오늘의 결과물, Gerrit CL 링크

28장

이슈 카드, 쉬움 19 · 보통 9

1분

소스 받기 252MB, 빌드 없음

문서

가이드

  • 시작하기— 오늘 하는 일, 일정, 결과물
  • 사전 준비— 행사 전에 끝낼 계정과 도구 설치 (집에서 30~60분)
  • 첫 CL 올리기— 소스 받기부터 업로드까지 0~5단계 (약 1시간)
  • 리뷰 받기— Start Review로 리뷰어 2명 지정, 코멘트 대응, 머지까지
  • 막혔을 때— 자주 나오는 오류와 해결, 셋업이 안 됐을 때의 대안

규칙

  • 기여 규칙— 행동 강령, CLA와 이메일, AUTHORS, 리뷰 예절, 보안 버그 신고
  • AI 도구 정책— 써도 되지만 직접 이해하고 책임지며, 사람에게는 사람이 답합니다

이슈 카드

  • 이슈 카드— 고칠 링크 28곳 — 쉬움 19 · 보통 9, 집에서 하는 코드 카드 10장

코드 기여

  • 코드 기여 가이드— 문서 다음 단계. 쉬운 정리부터 한 단계씩, 일감 찾는 법과 확인 방법
  • 코드 카드 (집에서)— crypto/hash 이전 카드 10장. Chromium 전체 빌드가 필요해서 행사 뒤 집에서 합니다

참고 자료

  • 자주 묻는 질문— 회사 이메일, 영어, AI, 리뷰가 없을 때, 머지, 다음 기여
  • 유용한 링크— Gerrit, Code Search, Issue Tracker 등 자주 여는 사이트
  • 용어— CL, 패치셋, 커미터, CQ 같은 낯선 말 정리
