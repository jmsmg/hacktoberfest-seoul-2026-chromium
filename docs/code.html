코드 카드 (집에서)

문서 카드를 끝내고 더 해 보고 싶은 분을 위한 카드입니다. Chromium의 옛 해시 함수(crypto/sha2.h, crypto/secure_hash.h)를 새 API(crypto/hash.h)로 바꾸는 일이고, 이슈 372283556 아래에서 진행 중입니다. 고친 코드를 직접 빌드하고 테스트를 돌려야 해서 행사장이 아니라 집에서 합니다. 카드 목록은 이슈 카드 아래쪽에 있습니다.

준비물#

  • 디스크 100GB 이상, 메모리 16GB 이상. 소스를 받는 데 한두 시간, 첫 빌드에 몇 시간 걸립니다.
  • 행사 때 받은 src/는 문서 폴더만 받은 것이라 빌드할 수 없습니다. 새로 받습니다.
  • 받는 방법은 운영체제별 공식 안내를 따릅니다: Linux · macOS · Windows. 한국어로는 OSSCA Chromium 가이드에 정리돼 있습니다.

1단계. 받고 빌드 준비#

공식 안내의 "Get the code"와 "Setting up the build"까지 합니다. out/Default를 만들 때 아래 세 줄을 넣으면 빌드가 빨라집니다.

gn args out/Default   # 편집기가 열리면 아래 세 줄을 넣고 저장
is_component_build = true
symbol_level = 0
blink_symbol_level = 0

2단계. 카드 고르기#

이슈 카드에서 하나를 골라 GitHub 카드에 "제가 할게요" 댓글을 남깁니다. 쉬움은 안 쓰는 include 줄을 지우는 카드, 보통은 옛 함수 호출 1~2곳을 바꾸는 카드입니다.

cd src
git new-branch crypto-hash-c6   # 카드 번호에 맞게

3단계. 고치기#

카드의 "할 일"대로 바꿉니다. 바꾸는 법은 아래 표와 같습니다.

옛 코드 새 코드
#include "crypto/sha2.h" #include "crypto/hash.h"
crypto::kSHA256Length crypto::hash::kSha256Size
crypto::SHA256Hash(x) crypto::hash::Sha256(x)
crypto::SHA256HashString(x) std::string(base::as_string_view(crypto::hash::Sha256(x))), 그리고 #include "base/strings/string_view_util.h"
base::HexEncode(crypto::SHA256HashString(x)) base::HexEncode(crypto::hash::Sha256(x))
  • include만 지우는 카드는 #include "crypto/sha2.h" 줄만 지웁니다. 그 파일이 std::array나 base::span을 쓰는데 직접 include가 없으면 빌드가 깨질 수 있으니, 그때는 <array>나 "base/containers/span.h"를 넣습니다.
  • 앞서 머지된 CL을 보면 감이 옵니다: 8264232(include 지우기), 8505842(SHA256HashString 바꾸기), 8382616(kSHA256Length 바꾸기).

4단계. 빌드하고 테스트#

카드의 "확인" 명령을 그대로 돌립니다. 예를 들면 이렇습니다.

autoninja -C out/Default components_unittests
out/Default/components_unittests --gtest_filter='EncryptionUtils*'
  • include만 지우는 카드는 그 파일만 컴파일해 볼 수도 있습니다. 경로 앞에 ../../, 뒤에 ^를 붙입니다: autoninja -C out/Default ../../net/cert/cert_verify_proc.cc^
  • 빌드와 테스트가 모두 통과해야 올립니다.

5단계. 커밋과 업로드#

git cl format
git commit -a
git cl upload -f --hashtag=hacktoberfest-seoul-2026

커밋 메시지는 카드 제목에서 [code] 를 뺀 것을 제목으로 씁니다.

password_manager/leak_detection: migrate to crypto/hash APIs

Replace crypto::SHA256HashString with crypto::hash::Sha256 and drop
the crypto/sha2.h include.

Bug: 372283556

첫 기여라면 AUTHORS에 이름도 넣습니다(첫 CL 올리기 3단계).

6단계. 리뷰 요청#

Gerrit에서 Start Review를 누르고 카드의 리뷰어 후보 중 첫째와 둘째를 넣습니다. 참가자 계정은 봇 검사(dry run)도 CQ+2도 걸 수 없으니 메시지에 부탁을 적습니다.

Part of the crypto/hash migration (crbug.com/372283556). I don't have
try job access, so could you start a CQ dry run, and Submit to CQ once
it's approved?

그다음은 리뷰 받기와 같습니다. 막히면 Discord 스레드에 명령과 출력을 붙여 올려 주세요.
